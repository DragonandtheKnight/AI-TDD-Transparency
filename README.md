# CS100 AI-TDD Transparency

This repository documents AI-assisted Test-Driven Development (TDD) for our CS100 team project.

## Repository Structure

https://github.com/DragonandtheKnight/Dragon-and-the-Knight

The reports mirror the directory structure of the main project's source code. Each Markdown file corresponds to a source file.

```text
├── README.md
├── README-Template.md
└── src/
    ├── card/
    │   ├── Card.h.md
    │   └── CardRarity.h.md
    ├── game/
    │   └── Game.h.md
    ├── level/
    │   ├── Level.h.md
    │   └── LevelType.h.md
    ├── main.cpp.md
    ├── map/
    │   └── FloorMap.h.md
    └── player/
        └── Player.h.md
```

## Reporting Guidelines

- Follow the same directory structure as the source code.
- Keep reports updated.
- Include human contributions and test verification.


Use [README-Template.md](README-Template.md) as the template for each report.
